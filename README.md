# Каталог номеров СоцГума

Статический сайт-каталог. Данные ведутся в Google Таблице, сайт собирает робот (GitHub Actions) и публикует на GitHub Pages.

## Как это работает

Google Таблица → `build.py` (проверка данных, оптимизация обложек, генерация страниц) → GitHub Pages.

Если в таблице ошибка, сайт не обновляется, а в отчёте сборки (вкладка Actions → последняя сборка → Summary) написано, на каком листе и в какой строке.

## Что где лежит

- `data/template.xlsx` — пустой шаблон таблицы, `data/demo.xlsx` — демо-данные (выдуманные)
- `covers/` — обложки номеров: файл `<ID номера>.jpg` (или .png/.webp) либо имя файла в столбце «Обложка»
- `templates/`, `assets/` — внешний вид сайта
- `config.json` — название сайта, адрес, ссылка на сайт СоцГума
- `build.py` — сборщик

## Подключить свою таблицу

1. В Google Таблице: Настройки доступа → «Все, у кого есть ссылка» → «Читатель». Редакторов добавляйте по почте отдельно.
2. Скопируйте ID таблицы из адреса: `docs.google.com/spreadsheets/d/<ID>/edit`.
3. В репозитории: Settings → Secrets and variables → Actions → вкладка Variables → New repository variable: имя `SHEET_ID`, значение — ID.
4. Actions → «Собрать и опубликовать каталог» → Run workflow.

Без переменной `SHEET_ID` собираются демо-данные с пометкой «Демонстрационные данные».

## Локальная сборка

    pip install -r requirements.txt
    python build.py                 # демо
    SHEET_ID=... python build.py    # из Google Таблицы
    SHEET_FILE=путь.xlsx python build.py

Результат — папка `site/`.

## Важно знать

- Расписание (раз в сутки) GitHub отключает, если в репозитории 60 дней нет активности. Тогда сборку можно запустить кнопкой Run workflow, и расписание снова включится.
- Шрифты Unbounded и Golos Text лежат в `assets/fonts/` вместе с лицензиями (OFL).
